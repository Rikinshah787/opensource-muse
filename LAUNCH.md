# Launch OpenSource Muse

OpenSource Muse is meant to be a public, self-hostable agent workspace: inspectable plans, visible tool use, local-first sample mode, and an agent computer people can run themselves.

## GitHub Launch Checklist

- Publish the repo as `Rikinshah787/opensource-muse`.
- Add topics: `ai-agent`, `opensource`, `react-native`, `expo`, `copilotkit`, `self-hosted`, `browser-agent`, `personal-agent`, `typescript`.
- Pin the live demo URL in the repo description.
- Pin a short demo clip or screenshot in the README.
- Open 3 beginner-friendly issues: docs polish, connector ideas, local setup feedback.
- Ask builders to star only if they want open personal-agent infrastructure to exist.

## Share Copy
